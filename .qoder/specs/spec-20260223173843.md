# AI-Powered Fashion Assistant App - Scaffolding Implementation Plan

## Goal

Scaffold the entire monorepo for an AI-powered fashion assistant app: React Native mobile frontend, 8 polyglot backend microservices + API gateway, shared GraphQL schemas, Docker/K8s/Terraform infrastructure, and CI/CD pipelines. All files are minimal stubs with health checks -- no business logic.

---

## Monorepo Directory Layout

```
Oasicord/
├── .github/workflows/          # CI/CD
├── apps/mobile/                # React Native + Expo (TypeScript)
├── services/

├── infrastructure/
```

## Verification Plan

After scaffolding, verify the following:

1. **Mobile app installs**: `cd apps/mobile && npm install` -- no errors
2. **Mobile app starts**: `npx expo start` -- Expo dev server launches
3. **API Gateway runs**: `cd services/api-gateway && npm install && npm run dev` -- GraphQL playground at localhost:4000
4. **Python services start**: `cd services/fashion-transform && pip install -r requirements.txt && python -m src.main` -- health check responds
5. **Go services compile**: `cd services/media-storage && go build ./...` -- no errors
6. **Docker Compose**: `docker-compose build` -- all images build; `docker-compose up` -- all services healthy
7. **Health checks**: `bash scripts/health-check.sh` -- all 9 services return `{"status":"ok"}`
8. **Terraform validates**: `cd infrastructure/terraform && terraform init && terraform validate` -- no syntax errors
9. **CI workflow syntax**: Push to repo, verify `.github/workflows/ci.yml` is valid
